## Team Officers (DA.4)

### Driverless System Officer (DSO)

- One or more DSOs required per team
- At least one DSO must **not** be a driver
- Must be qualified to handle DS and deal with problems/failures
- **Responsibilities:**
  - Only person who can declare DS safe
  - Only person who can authorize Manual Mode or work on DS
  - Must accompany vehicle whenever operated/moved at competition (with DS installed)
  - Must be immediately available by phone at all times during event
  - Carries Remote Stop Control Box during driverless operation

## Driverless Inspection (DI.1)

### Required to Operate in Driverless Mode

All three must be passed:
1. Technical Inspection
2. Driverless Inspection
3. Emergency Brake System Test

### Bring to Driverless Inspection (DI.1.2)

- [ ] Data sheets for **all** sensors
- [ ] Documents proving sensors meet local legislation
- [ ] Remote Stop Control Box
- [ ] Tools needed for Driverless Inspection
- [ ] Copies of any submitted Rules Questions with received answers

### Emergency Brake System Test (DI.2)

Dynamic test on a straight-line cone course:
- Accelerate in Driverless Mode to **≥ 40 km/h** within 20 m
- Remote Stop triggered at a specific point
- Must stop within **≤ 8.5 m** (may be scaled for wet conditions)
- Performed after other Technical Inspection items

---

## Post-Inspection Modifications (DI.3)

After Inspection Approval, the **only** permitted changes are:
- Adjustments of Driverless System sensors
- Coupling/decoupling actuators per DT.2.2
- Installing/removing protective sensor covers (if approved during inspection)

**All DS parts must stay installed** during the entire competition.
Removal or installation of any DS component **voids Inspection Approval**.

## Static Events — Driverless Scope (DS.1)

### Formula SAE Electric Design Event
- Driverless System must **remain on vehicle** for Design and Cost events
- Team provides itemized list of DS-specific components to judges
- DS components are **not judged** and **not scored** (no bonus or penalty)

### Formula SAE Electric Cost Event
- DS components **not judged**
- DS-only components don't need to be on Cost Report (team must prove if questioned)
- Vehicle Cost excludes DS components
- No score impact from DS components

### Driverless Design Event (DS.2) — 150 pts
- Evaluates understanding and execution of sensors, actuators, control logic, processing, and software
- Scored separately from FSAE Electric Design
- Follows FSAE Rules for Design Event (S.4) unless Event Handbook says otherwise
- Design Summary uses required template (see submissions above)
- Judging conduct and score sheets published on Event Website

---

## Vehicle Operation Rules at Competition (DO.2.1)

- Outside permitted areas: DSMS detachable handle/key must be **completely removed** and kept by DSO
- Lockout/tagout must be used
- Between start and finish line crossing: **no wireless communication to vehicle** (one-way telemetry from vehicle is OK)
- Remote Stop Control Box is the **only** device that may send commands during driverless operation
